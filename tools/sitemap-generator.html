Sitemap Generator

Generate a basic XML sitemap from any website's homepage. The tool reads the homepage's internal links (up to 50) and outputs valid sitemap XML with today's date as lastmod, ready to copy. Note: it only discovers links present on the homepage via a public proxy — for a complete sitemap, use your CMS or a full crawler.
