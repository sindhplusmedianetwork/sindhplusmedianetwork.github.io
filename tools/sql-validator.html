SQL Query Validator

A syntax sanity checker for SQL - not a full parser. It checks balanced parentheses and quotes (ignoring quoted strings), that the statement starts with a recognized keyword, flags stray double semicolons, warns on SELECT * and flags UPDATE/DELETE statements missing a WHERE clause. Results are reported as a clear pass/warn/fail list.
