Broken Link Checker

Scan a web page for broken links. Enter a URL and the tool extracts its links (same-site only by default, up to 25) and checks each one, sorting results into OK, broken, and could-not-check. Honest note: checks run through a public proxy with CORS limits — 'could not check' means the test was blocked, not that the link is broken.
