JWT Decoder

Paste a JSON Web Token to instantly see its decoded header and payload, with human-readable dates for the exp, iat and nbf claims plus a note on whether the token is expired. The signature is shown but cannot be verified without the secret key. All decoding happens locally — your token never leaves the browser.
