YAML to JSON Converter

Convert YAML to pretty-printed JSON with a built-in parser for the common YAML subset: indentation-based nested maps, lists with - items, auto-typed scalars (numbers, true/false, null, quoted strings stay strings), # comments and --- markers. Honest note: this is not full YAML 1.2 - anchors, multi-line scalars (| and >) and complex keys are not supported.
