FPSC changes CSS 2026 exam pattern: only one compulsory paper per day instead of two

SP
By Sindh Plus Media Network
November 14, 2026 · 1 min read
WhatsApp Facebook X

The Federal Public Service Commission has announced an important change for the CSS Competitive Examination 2026. According to a notification issued by the commission, only one compulsory paper will now be held in a day, whereas previously two papers were taken in a single day. The commission said the decision will apply from the CSS Competitive Examination 2026 and the same policy will continue afterwards.

It said the step aims to provide convenience to candidates and to make the conduct of examinations more organised and smoother. The commission added that the detailed timetable for the CSS Examination 2026 will be issued soon. Candidates have been advised to regularly visit the commission's website for the latest information and updates.
