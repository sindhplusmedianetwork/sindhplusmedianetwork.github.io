Android 'GhostMap' Flaw Can Trap Phones in Permanent Boot Loop With Just an App Install

SP
By Sindh Plus Media Network
November 08, 2026 · 2 min read
WhatsApp Facebook X

Bitdefender has disclosed an Android flaw called "GhostMap" in which installing a specially crafted app can trap a phone in a persistent reboot loop, without ever opening the app or granting a permission. Restarting or safe mode does not fix the problem, and in most cases a factory reset is the only way out, which can wipe local data. Researchers noticed the issue when a banking dropper APK found in the wild kept crashing their emulators during installation, and later found that the flaw was not in the malware but in Android's wrong handling of ZIP entry size and compression method.

An APK is a ZIP file in which size and compression information is written in several places, and two Android libraries read that information differently, so when the method is neither stored nor deflated, the file is mapped into memory larger than its real size, a segmentation fault occurs on reading and the process crashes. If the damaged file is a resource that the system server reads itself after installation, the system server repeatedly dies and restarts and the phone cannot complete booting. Bitdefender tested the flaw on a Pixel 10 running Android 17 with the August 5, 2026 security patch, recording 110 crash cycles in normal mode and 72 in safe mode about a second after installation, and safe mode did not help because the service reads the file before safe mode takes effect.

Bitdefender reported the issue twice to Google in August through the Android and Devices Vulnerability Reward Programme; Google replied "won't fix, could not reproduce" to the first report and, despite a working proof and instructions in the second, placed it outside the scope of security updates and sent it to the feature team for a future version. No persistent boot-loop attack has been seen in the wild so far, and the persistent crash loop was demonstrated as part of Bitdefender's own research, but the risk is considered serious because an attacker could hide the technique in a fake app to brick a phone or use the fear of a factory reset as pressure, so users are advised not to install APK files from unknown sources, to use only Google Play or trusted stores, and to keep cloud backups, while Android 10 and above are reported to be affected.
