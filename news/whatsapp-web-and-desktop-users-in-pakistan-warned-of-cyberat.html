WhatsApp Web and Desktop Users in Pakistan Warned of Cyberattacks on Windows PCs

SP
By Sindh Plus Media Network
October 26, 2026 · 1 min read
WhatsApp Facebook X

Pakistan's National Cyber Emergency Response Team has issued a high-level cybersecurity warning urging government officials and people handling confidential data to immediately stop using WhatsApp Web and Desktop on Windows computers. The advisory says attackers are impersonating government departments, officials and trusted contacts, and circulating malicious files through WhatsApp Web, WhatsApp Desktop and email, often disguised as important official documents. If users open and execute the malicious content, hackers could gain remote access to their Windows computers, steal passwords and obtain confidential information.

The warning stresses that users should not automatically trust messages from familiar contacts, since an unexpected document, attachment or suspicious link could be part of a targeted attack. National CERT has also advised users to regularly inspect WhatsApp's Linked Devices section, warning that an unfamiliar connected device could indicate unauthorised account access. As an urgent precaution, officials handling sensitive information have been told to stop using WhatsApp Web and Desktop on Windows computers, terminate suspicious sessions, avoid unverified attachments, never share passwords or one-time codes, and enable two-step verification.

The advisory makes clear that this is not a nationwide WhatsApp ban, but a warning about the specific dangers of using WhatsApp Web and Desktop on Windows systems handling sensitive information.
